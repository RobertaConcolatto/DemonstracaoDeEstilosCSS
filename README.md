# Projeto HTML e CSS

Projeto desenvolvido em grupo durante o primeiro semestre da disciplina de Introdução à Computação, como parte de um curso EAD sobre HTML, CSS e Bootstrap.

##Objetivo

Demonstrar diferentes possibilidades de estilização utilizando CSS externo em páginas com a mesma estrutura HTML.

O projeto possui 4 páginas HTML com conteúdo e estrutura semelhantes, alterando apenas os arquivos CSS utilizados em cada página, permitindo comparar diferentes estilos visuais aplicados ao mesmo conteúdo.

# Tecnologias utilizadas

- HTML5
- CSS3

# Estrutura do projeto

- 4 páginas HTML
- Arquivos CSS externos independentes
- Estilizações diferentes aplicadas sobre a mesma estrutura base
